Aviator Data Collector (In-Browser)

Este script intentará recolectar datos de rondas de Aviator directamente desde tu navegador.

¡ADVERTENCIA! Los selectores del DOM (ej. `.game-multiplier-display`) son altamente específicos del casino y probablemente necesiten ser ajustados manualmente en el código JavaScript (en la sección `SCRIPT PRINCIPAL`). Abre las herramientas de desarrollador (F12) para inspeccionar el juego.

Para que el almacenamiento en `localStorage` y la descarga funcionen correctamente, debes abrir este archivo HTML a través de un **servidor web local** (ej. `http://localhost:8000/`).

Paso 1: Cargar el Juego Aviator

Una vez cargado el juego, es posible que necesites interactuar manualmente con él (ej. hacer clic en la pestaña "Historial" o en rondas específicas) para que la información de Provably Fair sea visible en el DOM.
